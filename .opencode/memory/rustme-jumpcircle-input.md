**12. STRAFE «СЛИШКОМ МЕДЛЕННЫЙ» (09-10 18:05, DLL 65 кл) — фикс.** Причина: запись dir×ref каждый тик СЪЕДАЛА спринт-прыжковый буст (vanilla +0.2/tick к motion на тике прыжка) и любой momentum (кнокбэк, разгон по льду) — в MC двигаются спринт-бхопом → медленнее ванили. Fixed: величина записи = **max(ref × Ускорение, curMag)** — (а) замедление стрейфа по-прежнему снимается (ref ≥ замедленной скорости), (б) всё, что игра сама разогнала выше эталона, СОХРАНЯЕТСЯ (только направление поворачивается под инпут — бхоп-редирект как у легитных читов), (в) разгон не клампится (curMag > ref во время разгона → пишем curMag). + слайдер «Ускорение» 0.5..1.6 (def 1.0) — множитель эталона, если юзеру всё ещё медленно. Математика равновесия EMA (пост-драг замер = (ref+accel)×drag) сходится в естественную скорость — систематического занижения нет, буст был главным.
