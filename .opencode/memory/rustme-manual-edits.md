Юзер (09-10, после трёх поломок подряд при порте JumpDistort): «пиши вручную а не с помощью скриптов и ничего не будет ломаться».

**Why:** bash/python-хередоки, правящие исходники, портят экранирование — последовательность `\n` внутри Java-строк (`"...текст\n" +`) превращалась в реальный перенос строки: склеивались/рвались строки Shaders.JUMP_FSH, терялись методы JumpDistort (три инцидента за одну сессию).

**How to apply:** любые правки исходников — только Edit/Write вручную. Скрипты допустимы для чтения/анализа (дизасм, grep, извлечение таблиц), но не для записи в файлы исходников. Если правка большая — Write файла целиком вручную. Связано: [[rustme-jumpcircle-input]], [[rustme-phase-gating]], [[rustme-no-file-versioning]].
