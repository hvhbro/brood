**Их функция предикта = 0x2ae10 (вызывается из aimmain 0x2c530 через 4 точки). Ballistics 0x29440 зовётся из 0x2b0fd/0x2b1b0 (цикл 3 итерации, edi=3).**

**АЛГОРИТМ (все константы из .rdata/.data резолвлены):**
1. Гейт: ammoType<0 ИЛИ aimPredictScale≤0.001 → out = pos без предикта.
2. `k = clamp(elapsedSec*20 + aimLatency*0.02*aimPingComp, 0, 6)` — ТИКИ. elapsed = время с (ре)аквизишна цели (struct+0x50). aimLatency = config 0x33603c (их пинг ms), pingComp = 0x2fe660 (0.5).
3. Первый член: `pred = pos + vel*k` (vel — сдвиг за ТИК, из 0x299d0; Y-член только при aimPredictY-флаге 0x2fe0ab, иначе Y остаётся pos).
4. `k2 = clamp(aimPredictScale, 0, 2) × factor` — factor = struct+0x1a8, стартует 1.0 (0x29ab5/0x29c06 ставят 1.0 на путях count<4; в ветке ≥4 — адаптивный клампнутый коэффициент, мы портируем как 1.0).
5. Если k2>0.001: **3 итерации фиксированной точки**: distH = ГОРИЗОНТАЛЬНОЕ расст. pred↔мой глаз (r15 = Vec2 x,z!); ticks = ballistics(distH, ammo); `pred = pos + vel*(k + ticks*k2)`.
6. Y-drop (добавляется ВСЕГДА, даже при predictY=off): distH от ФИНАЛЬНОГО pred; `distH≤10 → max(0,tbl[0]); <200 → лерп по (distH−10)/10, idx=clamp(floor,0,18), ВЕРХНИЙ сэмпл клампится max(0,tbl[idx+1]), нижний как есть; ≥200 → max(0,tbl[19]); ×mult`. Таблицы: ammo 0/5 → 0x176110 [0.0617..23.2039] mult 1.0/0.45; 1/4 → 0x1760c0 [−0.0223..10.0473] 1.0/0.55; 2/3 → 0x176160 [−0.0165..5.6637] 1.0/0.6 (mult: ammo5=0.45@0x2b255, 4=0.55@0x2b27e, 3=0.6@0x2b2a7, остальное 1.0@0x2b2b1).
7. out = (predX, predY, predZ) → W2S/поворот.

**Их per-target struct (0x2a840, stride 0x1b0):** +0x20 last pos, +0x38..0x40 vel (сдвиг/тик, кап len 5), +0x44 prev frame pos, +0x50 trackingSince (double), +0x5c/+0x120 кольцо 16 снимков (12Б поз + 8Б время, дедуп <15мс), +0x1a0 count, +0x1a4 head, +0x1a8 factor. Ресеты: сдвиг >25м ИЛИ стоянка >0.25с → vel=0, factor=1.0, trackingSince=now. **У них НЕТ distance-гейта на снимках — кольцо чисто временнОе** (наш фикс 150мс это эквивалент; наш MAG0-гейт оставлен как доп. фильтр шума).

**Наши соответствия:** vel у нас блоков/сек (delta/dt) → их vel×ticks = наш vel×ticks×0.05 = vel×flightSec ✓; pingMs берём РЕАЛЬНЫЙ (Watermark.resolvePing, сделал public); Prediction-слайдер = их aimPredictScale (кламп 0..2); новый тоггл "Predict Y".
