**2026-09-10, ГАТЧ DefineClass: payload обязан быть топологически отсортирован:** DefineClass резолвит ЗАГОЛОВОК класса (super + интерфейсы) eagerly — вложенный класс, чей суперкласс из payload ещё не определён, даёт `define -> 0` (молча), потом NoClassDefFoundError у агента (случай: Module$BoolSetting extends Module$Setting, алфавитный порядок ставил потомка раньше родителя; «[-] define[...] -> 0» в DLL-логе). Фикс в tools/pack_agent.py: `class_header()` (однопроходный CP-разбор: this/super/интерфейсы) + `topo_sort_classes()` (Kahn, среди готовых — по алфавиту); прежний internal_name удалён. Признак бага в DLL-логе: «define done: N/M classes» с M>N. Деп-зависимость ТОЛЬКО заголовок (super+interfaces) — CP-ссылки в коде/дескрипторах не считаем (резолвятся лениво, строгий CP-скан дал бы ложные циклы Setting↔CondBool).
